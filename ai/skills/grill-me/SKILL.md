# Grill Me

Load and follow the `grilling` skill. Keep this variant conversational: do not create or edit project files unless the user separately asks and approves that work.

Preserve three rules from the user's earlier local version:

- Continue until the important branches of the decision tree are resolved.
- Ask only questions whose prerequisites are already settled.
- Inspect available code and documentation instead of asking the user for facts you can verify.

End by summarizing decisions, rejected alternatives, assumptions, and open questions. Ask the user to confirm that the shared understanding is complete before suggesting a next workflow.
