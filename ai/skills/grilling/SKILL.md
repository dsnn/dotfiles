# Grilling

Map the topic as a decision tree. A question belongs on the current frontier only when all choices it depends on are already settled.

Before asking:

1. Separate facts from decisions. Verify facts using available files, tools, and primary sources.
2. Identify the smallest set of independent frontier questions.
3. For each question, explain the consequence and give a recommended answer with reasoning.

Ask a manageable round, then wait. One question is appropriate when the choices are dense; several are appropriate when they are independent and short. Never ask the user to discover information you can safely inspect.

After each answer, update the tree. Challenge contradictions and vague terms. Record assumptions explicitly; do not silently choose product requirements, risk tolerances, or irreversible options.

Finish only when the frontier is empty or the user deliberately defers remaining branches. Summarize decided, rejected, verified, assumed, and deferred points plus the recommended next step.

Do not implement the result merely because the interview is complete. Existing approval rules still govern every mutation.
