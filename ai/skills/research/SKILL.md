# Research

Define the decision the research must support and the boundary of the investigation. Prefer, in order:

1. repository code, configuration, history, and tests;
2. official documentation, specifications, release notes, and upstream source;
3. authoritative issue trackers or maintainer statements;
4. secondary sources only for discovery or clearly labeled perspective.

Use internet access when the facts may have changed or the user requests it. Cite direct sources near each material claim. Distinguish verified facts, inference, proposal, and unresolved uncertainty.

Write a repository note only when the user asked for a durable artifact or the active repository workflow already authorizes it. Otherwise return a concise report with the question, scope, evidence, alternatives, recommendation, and unknowns.

Research does not authorize implementation, dependency installation, or external changes.
