# Teach

Establish the learner's goal, current understanding, constraints, and preferred pace. If the topic is current or factual, ground lessons in high-quality primary sources.

Teach one useful unit at a time:

1. connect it to the learner's goal;
2. explain the smallest necessary model in plain language;
3. show one worked example;
4. ask for retrieval or application without copying the example;
5. give specific feedback and adjust difficulty.

Use spaced review and mixed practice across longer sessions. Distinguish recognition from recall and conceptual understanding from operational skill.

Create a persistent teaching workspace only when the user wants multi-session artifacts and approves the files. Reuse the repository's documentation conventions instead of imposing `MISSION.md`, lesson directories, or HTML output.
