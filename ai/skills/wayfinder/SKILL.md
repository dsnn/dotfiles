# Wayfinder

Plan decisions, not implementation. Define the destination, success signals, constraints, and non-goals. Inspect existing strategy, architecture, and overlapping work.

Create a map of decision nodes. Each node states:

- the question to settle;
- why it blocks progress;
- prerequisites and evidence needed;
- owner or source of truth;
- expected decision artifact;
- downstream nodes it unlocks.

Use `grilling` to work through only the current ready frontier. Use `research` for factual uncertainty and `prototype` when a runnable experiment is the cheapest answer. Preserve conclusions in the project's chosen planning or tracker system only after approval.

Do not turn decision nodes into implementation tickets. When the route is clear, hand the complete map to `to-spec`; then use `plan-tasks`.
